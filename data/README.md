# Data attribution

`inputs.json.gz` contains 300 selected examples from Google DeepMind and Google Research's [FACTS Grounding](https://huggingface.co/datasets/google/FACTS-grounding-public), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). See [Jacovi et al., 2024](https://storage.googleapis.com/deepmind-media/FACTS/FACTS_grounding_paper.pdf).

The subset is repackaged as compressed JSON with renamed fields and local IDs. Question/context text is unchanged; other upstream fields are omitted. Numerical annotations and splits are outputs of this study.
